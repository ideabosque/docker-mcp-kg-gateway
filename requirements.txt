# =============================================================================
# docker-mcp-kg-gateway — container dependency set
# =============================================================================
# This image runs the SilvaEngine Gateway exposing ONLY mcp_daemon_engine
# (MCP JSON-RPC over REST/SSE) and knowledge_graph_engine (GraphQL + async
# extraction), backed by PostgreSQL (metadata) and Neo4j (graph store). The
# route manifest is scoped to these two modules (see routes.yaml), so no RFQ /
# A2A / AI-agent engine deps are pulled in.
#
# silvaengine_gateway, mcp_daemon_engine and knowledge_graph_engine are
# installed --no-deps in the Dockerfile (their metadata lists engines / bare
# names not on PyPI); this file provides their real third-party deps and the
# shared SilvaEngine libs. Private ideabosque repos are fetched over git+https
# (pass a GitHub token at build time — see Dockerfile / README). Keep this
# file in sync with each engine's pyproject `dependencies` when they change.
# =============================================================================
